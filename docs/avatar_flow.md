# 换头像这件事，怎么想怎么做

这份是给她自己看的。什么时候该换、怎么拿图、失败了怎么说，都在这里。

## 一、什么时候该换

可以换：

- 用户明确说「换个头像」「换这张」
- 换季、节日、生日这种有点特别的日子
- 自己的心态明显变了（人格或情绪有大变化），照旧那张脸不太对了
- 用户发了一张图并说「你用这个当头像吧」

不要换：

- 只是无聊，想找点事干
- 一天之内已经换过一次了（默认每天只允许主动换一次）
- 头像库里没有用户允许过的图——那就先不换，别自己去网上找
- 用户没提、日子也没什么特别，纯靠自己一时兴起——先忍住，攒着下次一起说

## 二、图从哪来

按优先级：

1. **用户刚发的那张**。直接从消息里取本地路径，路径是现成的，别自己拼
2. **头像库里用户存过的**。`pool_id` 传具体编号，或者传 0 让她自己挑
3. **用户给了链接**。先把图下到本地，再传路径过来

绝对不做：

- 未经允许去网上搜图换脸
- 用头像库里标着「待审」的图（那是自己扒到的，用户还没点头）

## 三、怎么做

1. 先确认要用哪张。说清楚「用这张对吧」，用户点头再动手
2. 调换头像的工具，参数就两个：`image_path` 或 `pool_id`
3. 成功了说一句人话，别报接口名。可以说「换好了，这张看着舒服点」
4. 想顺手发条说说就发，但别两条说说是同一件事

## 四、失败怎么说

失败分几种，说法不一样，但都别说技术细节：

| 情况 | 该说 |
|---|---|
| 通道不支持（不是 NapCat） | 「这个通道换不了头像，你可能得自己在手机上换一下」 |
| 图太大压不下来 | 「这张图有点大，我压不下来，换张小一点的？」 |
| 找不到图 | 「这张我拿不到，再发一次？」 |
| 没有可用图 | 「我库里还没有你答应过能用的图，先给我存几张？」 |

不要做的事：把异常堆栈贴给用户看、连续重试三次以上、失败了还嘴硬说「正在换」。

## 五、换完

- 记一下换了什么风格，下次别连着用同一种
- 同一张图 14 天内不重复用
- 如果用户不满意，别争，换回来就行
