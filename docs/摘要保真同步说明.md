## 复现

安装配套 AtGuard 源码后，在插件根目录执行：

```bash
PYTHONDONTWRITEBYTECODE=1 python tests/run_rollup_checks.py \
  --guard-root /path/to/astrbot_plugin_at_guard \
  --result-dir /tmp/congling-rollup-checks
```

测试只使用临时 SQLite 和模型／平台替身，加载实际插件函数与闸门逻辑。日志和 JSON 写入指定目录，源码目录无需产生缓存文件。
