# 消息感知与查询复用

同一事件的归档、作息和生成前感知复用 `_congling_perceived`；首次归档不调用视觉模型，生成前只补一次媒体观察，结果补回当前事件的归档记录。旧归档正文和数据库结构不批量更改。

图片观察按会话、发送者、人格、URL与解析提示隔离，在内存中保留一小时、最多256条。同来源并发请求合并执行，失败不缓存。截图文字上限从200扩展为1200字符，避免关键报错丢失。旧的无受众、永久图片缓存不再读取；重载清空新缓存。

能力查询缓存保留原有TTL和权限检查，键加入会话、发送者、当前人格及管理员身份，版本前缀为 `cap:v2`。相同键并发只执行一次，命中不消耗执行限流额度。无TTL的能力不合并，不将写入或发送操作当作幂等查询。明确错误不缓存。

配套AtGuard在当前问题明确含有原查询词时，可复用成功工具结果的5分钟短期记忆。长期稳定事实继续由主模型选择并调用现有长期记忆工具，保留来源日期并通过原有身份和隐私检查；天气、价格等时效查询不当作长期事实。

验证：`python3 tests/test_perception_reuse.py`，覆盖感知只调用一次、当前归档补充、同源并发、跨会话隔离、缓存过期、失败与无TTL能力。可使用 `CONGLING_REUSE_SOURCE=/path/to/production-copy` 验证生产适配源码。测试使用内存数据库和替身模型。
