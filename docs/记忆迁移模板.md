## 字段规范

### 时间（必填）

格式 `YYYY-MM-DD HH:MM`，24 小时制。决定这条记忆在时间轴上的位置，也参与「最近新增」统计。
无法确定精确时间时，用当天 `12:00`，不要留空。

### 类型（必填）

只能取以下六个值之一：

| 值 | 含义 | 例子 |
|---|---|---|
| `fact` | 客观事实 | 望山是做插件定制的 |
| `pref` | 偏好、习惯 | 不喜欢香菜 |
| `event` | 发生过的事 | 昨天在群里吵架了 |
| `promise` | 承诺、约定 | 答应周末交付 |
| `relation` | 人际关系 | 洛琪希叫他主人 |
| `emotion` | 情绪状态 | 那天情绪很低 |

### 等级（选填，默认 3）

0–5 的整数，决定遗忘速度与保护级别：

| 等级 | 含义 | 会不会淡忘 |
|---|---|---|
| 0 | 不可遗忘（禁区、底线） | 永不衰减，受保护 |
| 1 | 极重要 | 几乎不衰减 |
| 2 | 重要 | 缓慢衰减 |
| 3 | 一般（默认） | 正常衰减 |
| 4 | 次要 | 衰减较快 |
| 5 | 琐碎 | 衰减最快 |

判不准就用 3。

### 标签（选填）

逗号分隔，最多 6 个，每个不超过 8 个字。用于检索与分类。
不要写句子，只写关键词。

### 来源（选填，默认私聊）

两种写法：

- `私聊` —— 归到与主人的私聊会话下
- `群 <群号>` —— 归到该群会话下，群号必须是纯数字

涉及群聊场景的记忆必须标群号，否则会全部落到私聊里，展示时来源是错的。

### 内容（必填）

- **单条 15–120 字**，最多不超过 200 字
- 写成一句完整、独立、脱离上下文也看得懂的话
- 用第三人称陈述，主语写清楚是谁（例：`望山说他…` 而不是 `他说…`）
- 不要写「今天」「刚才」这类相对时间，改成具体日期
- 不要包含 QQ 号以外的隐私信息（手机号、地址、密码等），导入端会拒收

5. 导入是**追加**，不会清空已有记忆；重复内容会被自动去重（按内容哈希）
