# AtGuard 主回复方式交接

从绫保持自身的感知、人设、关系、情绪、记忆、作息与醒后流程。AtGuard 只管理参与判定及主回复的引用、@、清理、模拟耗时和撤回保护；分段继续交给 AstrBot 原生流程。

当前事件由 AtGuard 成功登记 `_at_guard_reply_owner=at_guard` 时，`express_hook` 保留角色切换、醒后失败撤销及想继续睡的文案，再让出主回复清理、分句、引用和重复延迟。流式及工具结果也避免重复清理正文。没有该标记时，沿用从绫原生表达和发送节奏。

该交接不改变原生感知、人格注入、记忆召回、醒后爬楼、已读回写或后台任务管理。

本次提交基于已有 `codex/server-wake-persona-integration` 分支，只补充回复交接代码和说明。线上从绫使用现有服务器适配版本，其余适配和正在开发的功能不随本次 GitHub 更新覆盖。

AtGuard 的从绫交接回归执行真实方法体，覆盖群聊/私聊感知、原生上下文、人设开关、醒后或角色切换取消、工具结果、开启交接与关闭回退。模型、数据库与消息发送均在离线替身中执行。
